1. Nama dan Tujuan Aplikasi

Nama aplikasi Student Card Mini Project Flutter
Jenis aplikasi Aplikasi mobile Dibangun dengan Flutter dan Material 3

Student Card adalah aplikasi mobile sederhana untuk menampilkan identitas mahasiswa dalam bentuk kartu digital. Aplikasi ini juga menyediakan halaman profil, galeri foto, kontak, dan informasi tentang aplikasi.

Tujuan pembuatan aplikasi ini adalah menerapkan materi dasar Flutter: penggunaan widget teks, ikon, warna, dan container; penyusunan layout dengan Row dan Column; pengaturan jarak dengan margin, padding, dan SizedBox; penampilan gambar dari aset lokal; serta perpindahan halaman menggunakan Navigator.push dan Navigator.pop. Tema ungu dipilih agar seluruh halaman memiliki identitas visual yang konsisten.

2. Fitur Aplikasi

1

Beranda

Menampilkan ringkasan mahasiswa dan pintasan menuju halaman lain. Tombol Click Me membuka halaman Tentang Aplikasi.

2

Kartu

Menampilkan kartu mahasiswa berisi foto, nama, NIM, program studi, dan ikon email serta telepon.

3

Profil

Menampilkan data diri mahasiswa dalam baris label dan nilai: nama, NIM, dan program studi.

4

Galeri

Menampilkan foto mahasiswa berukuran besar dengan sudut melengkung dan keterangan foto.

5

Kontak

Menampilkan email dan nomor telepon. Teks kontak dapat diseleksi untuk memudahkan penyalinan.

6

Tentang Aplikasi

Halaman tambahan yang menjelaskan versi aplikasi, daftar halaman, dan kredit pembuat. Halaman ini dibuka dari tombol Click Me.

7

Navigasi dua arah

Setiap halaman dapat dibuka melalui bottom navigation dan tautan halaman. Tombol back pada AppBar mengembalikan pengguna ke halaman sebelumnya.

5. Alur Navigasi dan Pengiriman Data

Alur navigasi

Aplikasi memiliki lima halaman utama yang dapat dibuka dari bottom navigation maupun tautan halaman di bagian bawah setiap halaman. Kedua jalur memakai fungsi yang sama, yaitu openAppPage.

Bottom navigation / PageLinks
→
onNavigate(index)
→
openAppPage(context, index)
buildAppPage(index)
→
Halaman tujuan
→
AppBar back
→
Navigator.pop(context)
Setiap perpindahan halaman selalu melewati Navigator.push dan dapat dikembalikan dengan Navigator.pop.
Navigator.push( context, MaterialPageRoute<void>( builder: (routeContext) => buildAppPage( index: index, onNavigate: (target) => openAppPage(routeContext, target), ), ), );

Tombol back pada AppBar tersedia ketika halaman berada di atas tumpukan navigasi. Tombol tersebut memanggil Navigator.pop(context) sehingga pengguna kembali ke halaman sebelumnya. Halaman Tentang Aplikasi juga memiliki tombol Kembali yang memakai mekanisme pop yang sama.

Pengiriman data antarhalaman

Data yang dikirim antarhalaman adalah indeks halaman bertipe int. Halaman menerima callback ValueChanged<int> bernama onNavigate, lalu meneruskan indeks tujuan ke openAppPage. Daftar AppDestination memetakan indeks tersebut menjadi label, judul AppBar, dan ikon navigasi.

Data mahasiswa seperti nama, NIM, program studi, email, dan telepon ditulis sebagai konstanta pada masing-masing halaman. Tidak ada model data terpusat, state management, atau API. Karena itu, halaman tidak saling mengirim objek mahasiswa. Untuk pengembangan berikutnya, data dapat dipusatkan pada satu objek Student dan dikirim melalui konstruktor halaman atau MaterialPageRoute.

Pengujian. Widget test memeriksa perpindahan lima halaman, tombol back, serta alur Click Me menuju Tentang Aplikasi dan kembali. Perintah flutter analyze dan flutter test dijalankan untuk memastikan tidak ada error.
